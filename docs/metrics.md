# Расчёт метрик Seoul Bike Sharing Demand

## 1. Контекст анализа

Для расчёта метрик используется аналитическая витрина, подготовленная в лабораторной работе № 4:

` s3://mart/seoul_bike_sharing_demand/source_ingested_on=2026-10-13/hourly_rentals.parquet `

Период исходных данных: с 1 декабря 2017 года по 30 ноября 2018 года.

Выбранный аналитический вопрос:

> В какие часы суток и сезоны наблюдается различный уровень почасового спроса на велосипеды и как этот спрос отличается между праздничными и обычными днями?

Одна строка витрины соответствует одному часу наблюдения системы Seoul Bike в определённую календарную дату.

Составной ключ витрины: `date + hour`.

В витрине содержится 8760 почасовых наблюдений.

## 2. Определение метрик

Для анализа используются следующие основные метрики.

### Среднее количество аренд

`avg_rented_bikes` показывает среднее количество арендованных велосипедов за один функционирующий час.

В расчёт включаются только строки, для которых:

`functioning_day = true`.

Часы недоступности сервиса не включаются в среднее, поскольку нулевое количество аренд в эти периоды связано с отсутствием возможности воспользоваться сервисом, а не с обычным уровнем пользовательского спроса.

### Медианное количество аренд

`median_rented_bikes` показывает медианное количество арендованных велосипедов за один функционирующий час.

Для расчёта используются те же строки с `functioning_day = true`.

Медиана позволяет оценить типичное значение спроса и менее чувствительна к отдельным часам с очень высоким количеством аренд.

### Суммарное количество аренд

`total_rentals` показывает сумму `rented_bike_count` за функционирующие часы выбранной группы.

### Размеры групп

`observation_hours` показывает общее количество часовых наблюдений в группе.

`functioning_hours` показывает количество наблюдений, фактически участвующих в расчёте среднего, медианы и суммы аренд.

## 3. Общий итог

Для всей витрины получены следующие значения:

| Показатель | Значение |
|---|---:|
| Общее количество часовых наблюдений | 8760 |
| Количество функционирующих часов | 8465 |
| Суммарное количество аренд | 6 172 314 |
| Среднее количество аренд за функционирующий час | 729,16 |
| Медианное количество аренд за функционирующий час | 542 |

Среднее значение выше медианного на 187,16 велосипеда. Это показывает, что в наборе присутствуют часы с относительно высоким спросом, которые увеличивают среднее значение. Само это различие не объясняет причины высокого спроса.

## 4. Подготовленные результаты

### `metrics_main`

Основная группировка построена по:

`season + holiday + hour`.

Одна строка `metrics_main` соответствует одному сочетанию сезона, праздничного статуса и часа суток.

Таблица содержит:

- `season`;
- `holiday`;
- `hour`;
- `observation_hours`;
- `functioning_hours`;
- `total_rentals`;
- `avg_rented_bikes`;
- `median_rented_bikes`;
- `rental_share_pct`.

Всего сформировано 192 группы.

Поле `rental_share_pct` показывает долю каждой группы в общем количестве аренд. Для его вычисления используется оконная функция, рассчитывающая сумму `total_rentals` по всем группам. Для защиты от деления на ноль используется `NULLIF`.

Этот результат предназначен для сравнения почасового спроса между сезонами и праздничными/обычными днями в ЛР № 7.

### `metrics_detail`

Уточняющая группировка построена по:

`season + holiday + day_of_week + hour`.

Она содержит те же основные метрики, что и `metrics_main`, но дополнительно учитывает день недели.

Всего сформировано 960 групп.

Одна строка соответствует определённому сочетанию сезона, праздничного статуса, дня недели и часа суток.

Результат позволит в дальнейшем проверить, сохраняются ли закономерности основной группировки внутри отдельных дней недели.

### `rental_distribution_values`

Таблица содержит отдельные значения `rented_bike_count` для каждого часа, когда сервис функционировал.

В выборку включены только строки:

`functioning_day = true`

и

`rented_bike_count IS NOT NULL`.

Количество отдельных значений — 8465.

Эта выборка предназначена для построения распределения почасового спроса в последующей лабораторной работе.

## 5. Проверки расчётов

Для подтверждения корректности метрик выполнены несколько независимых проверок.

### Проверка 1. Размер основной группировки

Сумма `observation_hours` по всем строкам `metrics_main` должна совпадать с количеством строк исходной витрины.

Получено:

`8760 = 8760`.

Результат проверки: `true`.

### Проверка 2. Количество функционирующих часов

Сумма `functioning_hours` основной группировки должна совпадать с отдельным подсчётом строк `mart_source`, для которых `functioning_day = true`.

Получено:

`8465 = 8465`.

Результат проверки: `true`.

### Проверка 3. Сумма долей групп

Сумма `rental_share_pct` по всем непересекающимся группам основной группировки должна составлять примерно 100 % с учётом округления.

Получено:

`100,0 %`.

Проверка выполнена успешно.

### Проверка 4. Количество отдельных значений

Количество строк в `rental_distribution_values` должно совпадать с количеством функционирующих часов с известным значением `rented_bike_count`.

Получено:

`8465 = 8465`.

Результат проверки: `true`.

## 6. Ограничения

1. Среднее, медиана и суммарное количество аренд рассчитываются только по часам, в которые сервис функционировал. Нефункционирующие часы остаются в исходной витрине, но не включаются в эти показатели.
2. Размеры отдельных групп неодинаковы. Например, праздничные сочетания сезона и часа могут содержать значительно меньше наблюдений, чем обычные дни. Поэтому сравнение средних необходимо выполнять вместе с `functioning_hours`.
3. Среднее значение нельзя получать простым усреднением средних разных групп, поскольку группы имеют разные размеры.
4. Медиана для общего набора должна рассчитываться по исходным значениям, а не как медиана медиан отдельных групп.
5. Данные относятся только к Сеулу и охватывают один годовой период, поэтому наблюдаемые различия нельзя автоматически переносить на другие города или периоды.

## 7. Вывод

В ходе работы рассчитаны метрики почасового спроса на велосипеды на основе готовой аналитической витрины Seoul Bike.

Из 8760 часовых наблюдений 8465 соответствуют времени функционирования сервиса. За эти часы зарегистрировано 6 172 314 аренд. Среднее количество аренд составило 729,16 велосипеда в час, медианное — 542 велосипеда в час.

Различие между средним и медианным значениями показывает наличие часов с повышенным спросом. Основная группировка позволяет сравнивать этот спрос по сезону, праздничному статусу и часу суток, а уточняющая группировка дополнительно учитывает день недели.

При интерпретации необходимо учитывать неодинаковые размеры сравниваемых групп и то, что наблюдаемое различие метрик само по себе не устанавливает причину такого различия.
